KRYUK24 Bro Actions

Внутренний инструмент одного рекламодателя. Аккаунт Директа: smbatyan-armen82. Компания: КРЮК24, эвакуатор, Москва и Московская область, https://kryuk24.ru

1. Назначение

Приложение раз в сутки получает состояние собственных кампаний рекламодателя и показывает его владельцу во внутренней панели вместе с данными Метрики и Вебмастера. Изменения в кампаниях выполняются только после явного подтверждения владельца. Внешних пользователей у приложения нет.

2. Схема взаимодействия

Сервер владельцаPython 3, задача по расписанию один раз в сутки
→
API Директа v5 (JSON)OAuth-токен владельца аккаунта
→
Внутренняя панельпоказатели и предложения, кнопка подтверждения
→
Владелецподтверждает или отклоняет каждое изменение

4. Объем и ограничения

Один рекламодатель, до 10 кампаний, несколько десятков запросов в сутки, в пределах стандартного суточного лимита баллов. При ошибке или исчерпании баллов запросы прекращаются до следующего дня, владелец получает сообщение.

5. Хранение данных

Токен хранится на сервере владельца в файле с ограниченным доступом. Данные кампаний третьим лицам не передаются.
