## Նկարներ / Photos
Local project media/inbox -> originals(private, unchanged) -> prepared -> review -> publishedmanifest. Gev brings realphotos from WhatsApp or an explicitly linkedDrive inbox. Exact Drivefolder not set here.
Use contenthash to detect duplicate input. Preserve source, date received, permission/business relevance, editversion, destination and approval. Exported manifest names use neutral assetIDs, not clientnames/phones.
Light polish means restrained exposure/whitebalance/contrast/crop/resize, not replacing vehicle/location, inventing a completed job or adding equipment. Mask plate numbers, faces and incidental private information; strip locationmetadata from exports. Keep original untouched. When editing a supplied image in ChatGPT, use available image-editing capability; none has been run on new images in this package.
Prepare platform-specific variants only after checking current platform limits; do not invent upload dimensions/quotas. Beforepublish compare original/processed, inspect masking and preserve actualscene. One approvedbatch can cover specified assets/destinations; no standing approval assumed.
